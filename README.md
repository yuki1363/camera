# camera

ブラウザだけで動く、依存関係ゼロのシンプルなカメラアプリです。
`getUserMedia` API でカメラ映像をプレビューし、撮影した画像を PNG としてダウンロードできます。

## 機能

- カメラ映像のライブプレビュー（開始 / 停止）
- 撮影（ボタン、または `Space` キー）
- 撮影した写真の一覧表示・個別ダウンロード・削除
- カメラの切替（前面 / 背面）と、接続済みカメラの直接選択
- 解像度の切替（640×480 / 1280×720 / 1920×1080）
- プレビューの左右反転表示（保存される画像は反転しません）
- 権限拒否・カメラ未検出などのエラーを日本語で案内
- ライト / ダークテーマ対応、スマートフォン幅にも対応

## 使い方

カメラ API はセキュアコンテキスト（`https://` または `localhost`）でのみ動作します。
`index.html` をファイルとして直接開くのではなく、ローカルサーバー経由で開いてください。

```bash
# Node.js がある場合
npm start                      # http://localhost:8080 で起動

# Python がある場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開き、「カメラを開始」を押して権限を許可します。

## テスト

ブラウザ API に依存しない純粋関数を `src/lib/camera-utils.js` に分離してあり、
Node.js 標準のテストランナーで検証できます（追加インストール不要）。

```bash
npm test
# => tests 8 / pass 8
```

## 構成

```
index.html                  画面のマークアップ
src/styles.css              スタイル（ライト / ダーク対応）
src/app.js                  カメラ制御・撮影・ギャラリーの処理
src/lib/camera-utils.js     ブラウザ非依存の純粋関数
test/camera-utils.test.js   上記のテスト
```

## 動作環境

カメラ API に対応した最新のブラウザ（Chrome / Edge / Safari / Firefox）。
`facingMode` によるカメラ切替は主にスマートフォンで有効で、PC では接続済みカメラの一覧から選択してください。
